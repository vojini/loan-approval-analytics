# Loan Approval Analytics and Prediction System

## Project Overview

This project is developed as part of the Programming for Data Analysis module. It investigates a real-world loan approval dataset using Python-based data analysis, machine learning, clustering, dimensionality reduction, and interactive application development.

The project uses two loan approval datasets that are integrated and analysed to identify patterns associated with loan approval decisions.

## Project Objectives

The main objectives are to:

- Import, inspect, and merge multiple loan datasets using an appropriate primary key.
- Perform data cleaning and preprocessing.
- Investigate missing values, duplicate records, and outliers.
- Perform feature engineering for financial indicators.
- Conduct exploratory data analysis (EDA).
- Analyse relationships between applicant characteristics and loan approval.
- Develop a machine-learning model to estimate loan approval probability.
- Evaluate and improve model performance.
- Apply clustering techniques to identify groups of loan applicants.
- Explore PCA as a method for transforming sensitive numerical information.
- Develop an interactive application for loan prediction and data exploration.
- Apply Git and GitHub for version control and project management.
